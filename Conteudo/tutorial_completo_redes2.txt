SUMARIO DOS BLOCOS:
1. BLOCO 1 [Servidor | Usuario Comum]     : Reconhecimento inicial e identificacao
2. BLOCO 2 [Servidor | Usuario Admin/root]: IP estatico e configuracao de placas
3. BLOCO 3 [Servidor | Usuario Admin/root]: IP forwarding, NAT (Masquerade) e Firewall
4. BLOCO 4 [Servidor | Usuario Admin/root]: Servidor ISC-DHCP
5. BLOCO 5 [Cliente  | Usuario Admin/root]: Cliente DHCP e testes de conectividade
6. BLOCO 6 [Servidor | Usuario Admin/root]: SSH seguro e usuarios
7. BLOCO 7 [Cliente  | Usuario Comum]     : Conexao remota SSH
8. BLOCO 8 [Servidor | Usuario Admin/root]: Instalacao e configuracao do Samba
9. BLOCO 9 [Cliente  | Usuario Admin/root]: cifs-utils, .samba e montagem no fstab
10. BLOCO 10 [Cliente | Usuario Comum]    : Validacao grafica e marcadores


--------------------------------------------------------------------------------
BLOCO 1: RECONHECIMENTO INICIAL
- Maquina: Servidor
- Usuario: Comum (Prompt: $)
--------------------------------------------------------------------------------
1. Identificar o usuario conectado:
   whoami

2. Exibir o nome da maquina:
   hostname

3. Listar as placas de rede ativas:
   ip a
   *Identifique a placa externa de Internet (ex: enp0s3) e a interna LAN (ex: enp0s8).*

4. Alternar para o usuario administrador:
   su -
   *Digite a senha do root. O prompt passara de '$' para '#'.*


--------------------------------------------------------------------------------
BLOCO 2: CONFIGURACAO DE INTERFACES DE REDE
- Maquina: Servidor
- Usuario: Admin / root (Prompt: #)
--------------------------------------------------------------------------------
1. Editar o arquivo de interfaces:
   vi /etc/network/interfaces

2. Definir IP estatico na placa da rede interna (exemplo: 192.168.10.1):
   auto enp0s8
   iface enp0s8 inet static
       address 192.168.10.1
       netmask 255.255.255.0
   (Salvar com Esc + :wq)

3. Reiniciar a interface:
   ifdown enp0s8
   ifup enp0s8

4. Verificar se o IP foi configurado:
   ip a show enp0s8


--------------------------------------------------------------------------------
BLOCO 3: ROTEAMENTO, NAT E FIREWALL
- Maquina: Servidor
- Usuario: Admin / root (Prompt: #)
--------------------------------------------------------------------------------
1. Habilitar repasse de pacotes IPv4 no kernel:
   vi /etc/sysctl.conf
   *Descomente a linha: net.ipv4.ip_forward=1*
   (Salvar com Esc + :wq)

2. Ativar regra de NAT (Masquerade):
   iptables -t nat -A POSTROUTING -o enp0s3 -s 192.168.10.0/24 -j MASQUERADE

3. Salvar regras do firewall no disco:
   iptables-save > /etc/iptables/rules.v4

4. Conferir as regras salvas:
   cat /etc/iptables/rules.v4


--------------------------------------------------------------------------------
BLOCO 4: INSTALACAO E CONFIGURACAO DO SERVIDOR DHCP
- Maquina: Servidor
- Usuario: Admin / root (Prompt: #)
--------------------------------------------------------------------------------
1. Instalar o pacote DHCP:
   apt-get update
   apt-get install isc-dhcp-server -y

2. Definir a placa que responde ao DHCP:
   vi /etc/default/isc-dhcp-server
   *Configurar: INTERFACESv4="enp0s8"*
   (Salvar com Esc + :wq)

3. Definir o range e parametros de rede no arquivo de configuracao:
   vi /etc/dhcp/dhcpd.conf
   *Inserir o bloco:*
   subnet 192.168.10.0 netmask 255.255.255.0 {
       range 192.168.10.100 192.168.10.200;
       option routers 192.168.10.1;
       option domain-name-servers 8.8.8.8, 8.8.4.4;
       default-lease-time 600;
       max-lease-time 7200;
   }
   (Salvar com Esc + :wq)

4. Reiniciar o servico DHCP:
   service isc-dhcp-server restart


--------------------------------------------------------------------------------
BLOCO 5: CONFIGURACAO E TESTES DE REDE NO CLIENTE
- Maquina: Cliente
- Usuario: Admin / root (Prompt: #)
--------------------------------------------------------------------------------
1. Virar root no cliente:
   su -

2. Configurar a placa de rede para obter IP via DHCP:
   vi /etc/network/interfaces
   *Inserir:*
   auto eth0
   iface eth0 inet dhcp
   (Salvar com Esc + :wq)

3. Subir a interface cliente:
   ifdown eth0
   ifup eth0

4. Verificar se pegou IP do escopo:
   ip a

5. Testar conectividade local e externa:
   ping -c 4 192.168.10.1
   ping -c 4 8.8.8.8


--------------------------------------------------------------------------------
BLOCO 6: AJUSTES DE SEGURANCA SSH E USUARIO
- Maquina: Servidor
- Usuario: Admin / root (Prompt: #)
--------------------------------------------------------------------------------
1. Configurar o SSH:
   vi /etc/ssh/sshd_config
   *Defina uma porta customizada (ex: 2222) ou mantenha 22*
   *Defina: PermitRootLogin no*
   (Salvar com Esc + :wq)

2. Reiniciar o SSH:
   service ssh restart

3. Criar usuario de login comum se necessario:
   adduser aluno


--------------------------------------------------------------------------------
BLOCO 7: ACESSO REMOTO SSH
- Maquina: Cliente
- Usuario: Comum (Prompt: $)
--------------------------------------------------------------------------------
1. Retornar ao usuario comum:
   exit

2. Conectar remotamente:
   ssh -l aluno 192.168.10.1
   (Ou com porta especifica: ssh -p 2222 -l aluno 192.168.10.1)

3. Confirmar chave de autenticacao digitando 'yes' e inserir a senha.
4. Digite 'exit' para sair da sessao remota.


--------------------------------------------------------------------------------
BLOCO 8: SERVIDOR SAMBA (COMPARTILHAMENTO DE ARQUIVOS)
- Maquina: Servidor
- Usuario: Admin / root (Prompt: #)
--------------------------------------------------------------------------------
1. Instalar o Samba:
   apt-get install samba -y

2. Backup do arquivo de configuracao:
   mv /etc/samba/smb.conf /etc/samba/smb.conf.BKP

3. Criar a pasta publica e liberar permissoes:
   mkdir -p /mnt/dados
   chmod -R 777 /mnt/dados

4. Cadastrar a senha de rede Samba para o usuario:
   smbpasswd -a aluno

5. Criar o novo smb.conf:
   vi /etc/samba/smb.conf
   *Inserir:*
   [global]
       workgroup = RC2
       netbios name = Samba-Server RC2
       server string = %h Samba-Server RC2
       security = user
       log file = /var/log/samba/%m.%u.log
       max log size = 100000

   [homes]
       comment = Diretorio Pessoal
       valid users = %S
       read only = no
       browseable = yes
       create mask = 0700
       directory mask = 0700

   [publico]
       comment = Diretorio Publico
       path = /mnt/dados
       available = yes
       browseable = yes
       public = yes
       writable = yes
   (Salvar com Esc + :wq)

6. Reiniciar os servicos do Samba:
   service smbd restart
   service nmbd restart


--------------------------------------------------------------------------------
BLOCO 9: CLIENTE CIFS E MONTAGEM PERSISTENTE (/etc/fstab)
- Maquina: Cliente
- Usuario: Admin / root (Prompt: #)
--------------------------------------------------------------------------------
1. Virar root no cliente:
   su -

2. Instalar utilitarios cifs e vim:
   apt-get update
   apt-get install cifs-utils vim -y

3. Criar o diretorio local de montagem:
   mkdir -p /mnt/home
   chmod -R 777 /mnt/home

4. Criar o arquivo de credenciais:
   vi /root/.samba
   *Inserir:*
   user=aluno
   password=aluno
   workgroup=RC2
   (Salvar com Esc + :wq)

5. Bloquear permissoes do arquivo de credenciais:
   chmod 600 /root/.samba

6. Configurar montagem permanente no boot:
   vi /etc/fstab
   *Inserir no final:*
   //192.168.10.1/publico  /mnt/home  cifs  credentials=/root/.samba,iocharset=utf8,_netdev  0  0
   (Salvar com Esc + :wq)

7. Montar sem reiniciar:
   mount -a

8. Listar e validar se o diretorio remoto foi montado:
   ls -l /mnt/home


--------------------------------------------------------------------------------
BLOCO 10: INTERFACE GRAFICA E ATALHOS
- Maquina: Cliente
- Usuario: Comum (Prompt: $ / GUI)
--------------------------------------------------------------------------------
1. Voltar ao usuario comum:
   exit

2. Navegacao direta:
   Abrir o gerenciador de arquivos e digitar na barra de localizacao:
   smb://192.168.10.1/

3. Criar atalho rapido:
   Entrar em /mnt/home pelo gerenciador de arquivos e clicar em "Adicionar Marcador".
